# Borland C++ 2.0 1991-08 版的 `__SCROLL`

Borland C++ 2.0 有兩個出貨版本：1991-04 的磁片版與 1991-08 的改版（隨 Application Frameworks 套裝）。兩版的 C 函式庫只有 `SCROLL`
一個模組不同：8 月版修掉了 conio 視窗捲動一列時「空出的列沒有清空」的問題（說明見
[五份函式庫的全景](../../docs/00-overview/era-and-libraries.md)）。

`scroll-1991-08.json` 只收 8 月版 `CS`／`CC`／`CM`／`CL`／`CH.LIB` 裡 `SCROLL` 模組的樣式，共 5 筆（每個模型一筆），
以 `tools/gen_signatures.py make … --modules SCROLL` 產生。

## 怎麼用

一支用 conio 視窗函式（`window`、`cprintf` 捲動）的程式，同時掃 [`dos.json`](dos.md) 與本檔：

| `dos.json` 的 `__SCROLL` | 本檔 | 推論 |
|---|---|---|
| 命中 | 不命中 | 連結的是 1991-04 版函式庫 |
| 不命中 | 命中 | 連結的是 1991-08 版函式庫 |
| 不命中 | 不命中 | 程式沒有連結 `SCROLL`，或不是 BC++ 2.0 |

已證實（實測）：同一支 conio 測試程式分別連結兩版 `CS.LIB`，本檔在 8 月版執行檔命中 1 次、在 4 月版命中 0 次；`dos.json` 的 `__SCROLL` 則相反。

只有 `SCROLL` 可以分辨兩版，程式沒用到 conio 的視窗捲動時就分不出來。
